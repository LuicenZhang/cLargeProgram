# cLargeProgram

C 语言教学演示系统 — 控制台程序，把 C 语言的七章知识点做成可点选的两级菜单，选一项就跑一段可执行的示例代码。

广东海洋大学阳江校区食品科学与工程专业期末考核作业，2023 年。

> 这是期末作业，不是教学产品。知识点覆盖按课程要求来，深度以「能跑通、看得懂」为准。

---

## 它做什么

运行后是一个文字菜单，七个大类对应 C 语言的七个章节：

```
                C编程演示系统
    1. C基本数据        5. 函数结构
    2. 顺序结构         6. 数组结构
    3. 分枝结构         7. 指针结构
    4. 循环结构
    0. 结束
```

选一个进去，是该章的小节目录；再选一个，直接跑那段示例代码，看完按回车回上一层。

一共 **50 个演示**。

| 章节 | 小节 | 演示数 |
|---|---|---|
| 1. C 基本数据 | 数据分类、取值范围、存储字节、算术算符、类型转换、I/O 类型控制、`printf`、`scanf`、字符 I/O | 9 |
| 2. 顺序结构 | 程序结构、语句与复合、ASCII 码、周长与面积、输出图案 | 5 |
| 3. 分枝结构 | `if`、`if-else`、`if-else if`、`switch`、`goto`、`break`、`continue` | 7 |
| 4. 循环结构 | `while`、`do-while`、`for`、`break`、`continue`、`goto`、无限循环、循环嵌套 | 8 |
| 5. 函数结构 | 定义、调用、参数传递、返回值、递归调用、嵌套调用、声明 | 7 |
| 6. 数组结构 | 定义、初始化、引用、输入输出、一维数组、二维数组、字符数组 | 7 |
| 7. 指针结构 | 定义、使用、输入输出、指针与数组、指针与函数、指针与指针、`main` 的参数 | 7 |

演示的值是当场算的，不是打印硬编码的答案。比如「存储字节」用的是 `sizeof`，「取值范围」用的是 `SCHAR_MIN` 这些宏——换台机器结果会跟着变。

## 编译运行

**Windows + Visual Studio**（原开发环境）

双击 `cLarge Program.sln`，按 `Ctrl+F5` 运行。

工具集是 v143（VS 2022），字符集 Unicode。

**Windows + 命令行**

```bat
cl /EHsc /Fe:demo.exe "cLarge Program\*.cpp"
demo.exe
```

**其他平台**

代码本身是标准 C++ 控制台程序，但用了 `system("cls")` 清屏和 `rewind(stdin)` 清输入缓冲，这两处在 Linux / macOS 上要改：

```c
system("clear");        // 代替 system("cls")
```

`rewind(stdin)` 在 POSIX 上行为未定义，建议换成循环读掉剩余字符。

## 代码结构

```
cLarge Program.sln              Visual Studio 解决方案
cLarge Program/
├── main.cpp                    入口：主循环 + 一级菜单分发
├── cLargeProgramm.cpp          菜单绘制（七个章节的目录）
├── cLargeProgram.h             一级菜单函数声明
├── menu2_1.cpp ~ menu2_7.cpp   各章演示实现，共 50 个函数
└── menu2_1.h ~ menu2_7.h       各章函数声明
```

两个设计上的说明：

**菜单用空格数排版，不是 `printf` 格式化。** `local(m, n)` 先打 m 个换行再打 n 个空格，`colum_n(n)` 只打 n 个空格。这样每行缩进固定，在等宽字体终端里对齐。

**`#include` 出现在 `.cpp` 中间。** 每个 `menu2_x.cpp` 在定义菜单函数之前 include 自己的头文件，头文件里是各演示函数的声明。这个写法能编译，但不合常规——正常应该放文件顶部。

## 已知问题

老实列出来，免得读代码时困惑：

- **每次按键都要按回车**。`main.cpp` 里是 `cho0 = getchar(); getchar();`——第一个 `getchar()` 拿走字符，第二个拿走紧随其后的换行符。输入 `1` 加回车，两个 `getchar()` 刚好把 `1\n` 读干净，不会阻塞。但如果输入了 `1 2` 加回车，剩下的 `2` 还留在缓冲区，下一轮循环会直接吃掉它而不等你按键。
- **`lines_m(int)` 定义了但从没调用**，死代码。
- **`switch` 的 `default` 什么都不做**。输错字符会静默回到菜单，没有提示。
- **没有输入校验**。`scanf` 的返回值一律没检查。
- **`dispMenu2_x()` 没有声明在头文件里**，是文件内私有函数却用了外部链接，正确做法是加 `static`。

已修的：`menu2_1.cpp` 用了 `SCHAR_MIN`、`FLT_MIN` 这些宏却没 include `<limits.h>` 和 `<float.h>`。MSVC 的 `<iostream>` 会间接带进来，所以原开发机上一直没报错；换 clang 编译立刻失败。现已补上这两个头文件。

## 编码

源码是 **UTF-8 with BOM**。

原本是 GBK（Windows 中文环境默认），提交后 GitHub 上中文注释全是乱码，现在已转成 UTF-8 并加 BOM——这样 MSVC 在任何区域设置下都能正确识别，不会再被当成 GBK 解码。

`.h` 文件是纯 ASCII，没有加 BOM。
